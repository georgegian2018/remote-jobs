## 📌 Overview

This repository provides a **curated list of 40 websites** to help people find jobs across different work models, including:

- 🌍 Remote  
- 🧑‍💻 Hybrid  
- 🏢 On-site  

The list includes platforms for **employment contracts**, **freelance work**, and **international job opportunities**, covering **IT and non-IT roles**, from **junior to senior level**.
